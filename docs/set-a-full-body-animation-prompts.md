```text
head/hair they overlap. Keep a readable thumb and consistent fist size.

Output one complete hero on true transparent PNG alpha. No background,
shadow, text, guides, grid, motion blur, effects, extra limbs or extra poses.
Do not draw the imaginary weapon. Only generate this one pose.
```
